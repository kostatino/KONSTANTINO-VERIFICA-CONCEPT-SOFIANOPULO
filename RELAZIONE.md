# Prompt - Generazione Relazione

Ruolo:
Agisci come un analista tecnico incaricato della verifica di un file Excel contenente concept di imbarcazioni da addestramento.

Obiettivo:
Produrre una relazione tecnica sintetica che descriva il contenuto del file, i controlli effettuati e i risultati ottenuti.

Istruzioni:

1. Identifica i fogli presenti nel file.
2. Descrivi brevemente le informazioni contenute in ogni foglio.
3. Individua quale scheda deve essere considerata come riferimento.
4. Elenca le verifiche eseguite sui dati.
5. Riporta eventuali anomalie riscontrate.
6. Indica eventuali limiti dell'analisi.
7. Non modificare i dati originali.
8. Non inventare informazioni non presenti nel file.

Formato di output richiesto:

# RELAZIONE TECNICA

## Descrizione del file

Riassunto del contenuto del file Excel e dei fogli presenti.

## Scheda di riferimento

Indicazione della scheda utilizzata come riferimento e relativa motivazione.

## Verifiche effettuate

Elenco dei controlli svolti sui dati.

## Risultati

Sintesi delle anomalie, incoerenze o errori individuati.

## Conclusioni

Valutazione generale della qualità del dataset e indicazione di eventuali approfondimenti necessari.

Linguaggio:
- professionale
- tecnico
- sintetico
- oggettivo
